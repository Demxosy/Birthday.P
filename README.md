# For Pratiksha - A Friendship Page

A small, friendly web page made to show a best friend how special she is.
It celebrates **friendship only**. It has no photos and nothing romantic.

## What's inside

- Animated name hero with confetti
- "Your constellation": 8 tappable stars, each with a message
- Promises from a bestie
- Tap-for-sparkle wall of words
- Live countdown to the next birthday (1 January)
- A closing note

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `style.css` | All styling and colors |
| `script.js` | Interactions, countdown, confetti |
| `LICENSE` | Terms of use |

## How to run

1. Download all three files (`index.html`, `style.css`, `script.js`).
2. Keep them together in the **same folder**.
3. Double-click `index.html` to open it in any modern browser.

No install or internet connection is required. The page still works offline, and only the custom fonts need internet.

## Customize (with permission only)

Open `script.js` and edit the "EASY EDITS" section at the top:

- `FROM`: the sender's name
- `STARS`: the messages behind each star
- `WORDS`: the sparkle words

Colors live at the top of `style.css`.
